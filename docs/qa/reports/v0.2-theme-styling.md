## Что изменилось (история)

> Журнал изменений по снапшотам: каждая запись — что изменилось с прошлого прогона. Записи идут последовательно, сверху вниз (сверху — самая ранняя, снизу — самая свежая). Раздел ведёт агент; данные тестирования вносит пользователь.

### 2026-10-30 — итерация 1: оформление по теме, редактирование, Enter
- Поле — `St.Entry` (цвета текста/выделения/курсора/подсказки от темы) с многострочным `clutter_text`; диалог с классом `modal-dialog` темы; хардкод-цвета из CSS убраны.
- Кнопки — в стиле системных диалогов (`modal-dialog-button-box` / `modal-dialog-button`, равной ширины).
- Подсказка в пустом поле (`hint_text`), мин. высота поля — 4 строки от шрифта темы (следует масштабу шрифта).
- Enter / Shift+Enter — явная вставка перевода строки (`activatable: false` + обработчик); Ctrl+Enter — как раньше.
- Иконка панели — `icons/voice-input-helper-icon-symbolic.svg` (перекрашивается под панель), старая иконка удалена.
- ВРЕМЕННО: A/B скругления/тени (`VHI_QA_DIALOG=system` — системные, иначе свои 12px + тень) и DBG-лог фокуса (`DBG key-focus`, `DBG insert`) для диагностики диктовки в несколько заходов.
- Скрипты: `install.sh -n/--name` (имя/UUID), `restart-extension.sh` — справка, оговорка «перечитывает только CSS».

### 2026-10-30 — итерация 2: настройки (A/B), подсказка вверху, диагностика фокуса
- Итерация 1: Enter починен; подсказка была по центру поля по вертикали; фокус после вставки Myna уходит в `null` в ту же секунду (лог — в «Итоге»).
- Myna проверяется в ВМ VirtualBox (версия синхронизирована с хостом); пункты стабильности/журнала — на финальном прогоне без DBG-лога.
- A/B скругления/тени — теперь настройка в окне расширения («Собственное скругление и тень», ключ GSettings `custom-dialog-style`), переключается на лету; `VHI_QA_DIALOG` убран.
- Первые настройки расширения: схема `schemas/…gschema.xml`, `settings-schema` в metadata.json, `prefs.js` (Adw, `settings.bind`); `install.sh -i` компилирует схему.
- Подсказка: та же мин. высота у `hint_actor`, что у поля, — St.Entry больше не центрирует её.
- DBG-лог расширен (мс-метки): окно в фокусе Mutter, появление/исчезновение окон, JS-стек при сбросе фокуса в `null` — проверка гипотезы «фокус уводит исчезновение пилюли Myna (myna-shell)».

## Проверка многострочного поля (devkit)

Детальные проверки многострочного поля.

- [x] **Автоперенос.** Длинный текст (QA-хук `VHI_QA_TEXT=1`) переносится по словам, не уходит за правый край видимой области.
- [x] **Ширина.** Окно не шире 720px; при росте текста растёт только высота.
- [x] **Enter → перевод строки.** Курсор на новой строке, окно открыто, ничего не копируется (сигнал `activate` НЕ сработал).
- [x] **Ctrl+Enter.** Копирует и закрывает, без ошибок в логе.
- [x] **Esc.** Закрывает окно (фокус в поле).
- [x] **Фокус сразу.** Буквы печатаются сразу после открытия, без клика.
- [x] **Повторный клик по иконке.** Фокус возвращается в поле, текст не теряется.
- [x] **Навигация в многострочном.** Несколько переводов строк подряд; стрелки Up/Down двигают курсор по строкам, курсор не «вылетает».
- [x] **Копирование многострочного.** В буфер попадает текст с переводами строк `\n` (реальная вставка Ctrl+V — в основной сессии).
- [ ] **Стабильность сценария.** `.tmp/devkit.log` без `JS ERROR` на весь сценарий: открытие, печать, Enter, Ctrl+Enter, Esc, повторное открытие, очистка, отключение.
