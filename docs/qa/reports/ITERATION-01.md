## Проверка поля прототипа (devkit, Clutter.Text)

- [ ] **Автоперенос.** Длинный текст (QA-хук `VHI_QA_TEXT=1`) переносится по словам, не уходит за правый край видимой области.
- [ ] **Фиксированный размер.** Поле имеет заданную высоту; при росте текста окно не раздувается.
- [ ] **Enter → перевод строки.** Курсор на новой строке, окно открыто, ничего не копируется (сигнал `activate` НЕ сработал).
- [ ] **Ctrl+Enter.** Копирует и закрывает, без ошибок в логе.
- [ ] **Esc.** Закрывает окно (фокус в поле).
- [ ] **Фокус сразу.** Буквы печатаются сразу после открытия, без клика.
- [ ] **Повторный клик по иконке.** Фокус возвращается в поле, текст не теряется.
- [ ] **Навигация в многострочном.** Несколько переводов строк подряд; стрелки Up/Down двигают курсор по строкам, курсор не «вылетает».
- [ ] **Копирование многострочного.** В буфер попадает текст с переводами строк `\n` (реальная вставка Ctrl+V — в основной сессии).
- [ ] **Стабильность сценария.** `.tmp/devkit.log` без `JS ERROR` на весь сценарий: открытие, печать, Enter, Ctrl+Enter, Esc, повторное открытие, очистка, отключение.
