## Что изменилось (история)

> Журнал изменений по снапшотам: каждая запись — что изменилось с прошлого прогона. Записи идут последовательно, сверху вниз (сверху — самая ранняя, снизу — самая свежая). Раздел ведёт агент; данные тестирования вносит пользователь.

### 2026-10-27 — итерация 1: первый прогон
- Прототип: окно, иконка `edit-paste-symbolic`, многострочное поле `Clutter.Text`, Enter/Ctrl+Enter/Esc, копирование, QA-хук.
- Найден **блокирующий дефект**: окно не открывается по клику на иконку (`Clutter.InputPurpose.FREE_FORM` отсутствует в gjs/Clutter 18) → фикс в итерации 2.

### 2026-10-27 — итерация 2: фикс блокера input_purpose
- Убрана строка `input_purpose: Clutter.InputPurpose.FREE_FORM` (в gjs/Clutter 18 отсутствует).
- При повторном тестировании выявлен следующий **блокирующий дефект**: `Error: No property can_focus on ClutterText` (extension.js:165) → фикс в итерации 3.

### 2026-10-27 — итерация 3: фикс блокера can_focus (протестировано → новый блокер)
- Убрано свойство `can_focus: true` из `Clutter.Text` (у ClutterText его нет; фокус ставится через `global.stage.set_key_focus`).
- **Протестировано.** При повторной проверке выявлен следующий **блокирующий дефект**: `Error: No property track_hover on ClutterText` (extension.js:173; у `Clutter.Text` нет `track_hover`) → фикс в итерации 4.

### 2026-10-27 — итерация 4: фикс блокера track_hover (+ убран style_class)
- С `Clutter.Text` убраны несуществующие свойства: `track_hover`, `style_class` (стили поля перенесены на родителя), а также ранее `input_purpose` (в typelib есть, но обращение через `Clutter.InputPurpose.FREE_FORM` падало) — интроспекция подтвердила полный список.

### 2026-10-27 — итерация 5: попытка фикса клика по фону/панели (не помогла)
- С контейнера `VoiceInputModal` убраны `reactive`, `can_focus`, `track_hover` (перехватывали клики панели).
- Убран диагностический `cursor-changed` лог (шум в журнале).
- Поведение не изменилось — дефект UI/UX сохранился, требуется план (см. обсуждение, режим планирования).

### 2026-10-28 — итерация 6: отказ от grab, фикс клика по фону/панели, фикс геометрии окна (ожидает теста)
- **Убран `Main.pushModal`/grab** (актор-граб «глушил» панель): окно показывается поверх через `Main.uiGroup`, фокус предыдущего актора сохраняется/возвращается вручную (`_prevFocus`); `import Shell` убран.
- **Подложка `_bg`**: заменена геометрия на `MonitorConstraint({workArea: true})` (монитор минус панель) — раньше была нулевая высота/сдвиг на панель, клик по фону не ловился.
- **Ширина окна**: добавлен `max-width: 720px` в `.voice-input-modal-dialog` (фиксированная ширина MVP, пиксели; высота — авто). Настройка ширины — в бэклог (v1.4).
- **REQUIREMENTS.md**: зафиксированы UX-решения (панель доступна → фокус может уйти → возврат иконкой; клик по фону вне панели; скролл/настройка ширины — в бэклог v1.4/v1.5).
- Ожидает теста (чек-лист итерации 6).
