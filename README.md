# Voice Input Helper

Расширение GNOME Shell 50 для быстрого голосового ввода текста. Надиктованный через системное распознавание речи **Myna** (Ubuntu Speech-to-Text) текст попадает в буфер обмена — минимум действий между «хочу сказать» и «текст вставлен в приложение».

Проект находится на начальной стадии: полные требования (user stories с критериями приёмки) — в [REQUIREMENTS.md](REQUIREMENTS.md), рекомендации для ИИ-ассистентов — в [CLAUDE.md](CLAUDE.md). Код — прототип окна ввода с многострочным полем (Clutter.Text); полная реализация по ТЗ впереди.

## Планируемые возможности

- Открытие окна ввода одним кликом по иконке на верхней панели, с фокусом в поле ввода.
- Диктовка прямо в окно расширения через Myna (текст вводится в **многострочное** поле как при обычной печати; Enter — перевод строки, Ctrl+Enter — копировать и закрыть).
- Копирование текста в буфер обмена одной кнопкой, с системным уведомлением.
- Закрытие окна кнопкой, клавишей `Esc` или кликом по фону.
- Сохранение текста между открытиями окна в течение сессии.
- Быстрая очистка поля для следующей диктовки.

## Требования

- GNOME Shell 50 (проверено на Ubuntu 26.04, GNOME Shell 50.1).
- Ubuntu Speech-to-Text (Myna) для диктовки.

## Установка

```bash
./install.sh   # создаёт симлинк в ~/.local/share/gnome-shell/extensions
```

После установки перезапустите GNOME Shell (или перелогиньтесь) и включите расширение в приложении «Расширения».

## Разработка

```bash
./run-gnome-shell-devkit.sh   # изолированная devkit-сессия GNOME Shell
```

Полный лог пишется в `.tmp/devkit.log`, на экран выводятся только строки, относящиеся к расширению и JS-ошибкам.
