# Требования пользователя — Voice Input Helper

Версия: v1 (первая итерация).

## 1. Цель и назначение

Расширение GNOME Shell для **быстрого голосового ввода текста** с использованием системного распознавания речи **Myna** (Ubuntu Speech-to-Text). Пользователь надиктовывает текст, и он попадает в буфер обмена — минимальное количество действий между «хочу сказать» и «текст вставлен в приложение».

## 2. Пользовательская персона

Пользователь Ubuntu GNOME (GNOME Shell 48–50), который **диктует чаще, чем печатает**. Основной поток: надиктовал → вставил из буфера обмена в нужное приложение (письмо, чат, документ). Окно ввода должно появляться по одному действию и сразу принимать фокус и диктовку — без лишних шагов и кликов.

## 3. Сценарии использования (user stories)

Каждый сценарий — с критериями приёмки. Все критерии должны выполняться.

### US-1. Открытие окна по клику на иконку

Как пользователь, я хочу, чтобы **клик по иконке на верхней панели** сразу открывал окно ввода.

Критерии приёмки:
- Клик по иконке → окно ввода открывается немедленно, без промежуточного меню.
- Фокус с самого начала находится в поле ввода (можно печатать без дополнительного клика).
- Повторный клик по иконке при уже открытом окне не создаёт второй экземпляр: фокус возвращается существующему полю, введённый текст сохраняется.
- Иконка на панели — `edit-paste-symbolic` (символ вставки из буфера обмена).

### US-2. Диктовка текста через Myna

Как пользователь, я хочу надиктовывать текст прямо в окно расширения, чтобы не переключаться между приложениями.

Критерии приёмки:
- Поле ввода — настоящий `St.Entry` с корректным фокусом (`global.stage.set_key_focus`), видимый механизмам доступности и Wayland input methods.
- При активации Myna распознанный текст вводится в поле, как при обычной печати.
- Окно остаётся открытым во время и после диктовки.

### US-3. Копирование текста в буфер и закрытие

Как пользователь, я хочу, чтобы после диктовки текст одним действием ушёл в буфер обмена, а окно закрылось.

Критерии приёмки:
- Кнопка «Копировать» копирует всё содержимое поля в буфер обмена.
- Окно сразу закрывается, фокус возвращается ранее активному окну.
- Появляется уведомление о том, что текст скопирован (системное уведомление GNOME + заголовок окна меняется на «Текст скопирован»).
- При пустом поле «Копировать» показывает уведомление «Нечего копировать» и не закрывает окно (см. также раздел 4).

### US-4. Закрытие окна

Как пользователь, я хочу закрывать окно привычным способом — без поиска кнопки.

Критерии приёмки:
- Окно закрывается любым из трёх способов:
  1. кнопка «Закрыть» в окне;
  2. клавиша `Esc`;
  3. клик по затемнённому фону вне окна.

### US-5. Сохранение текста между открытиями

Как пользователь, я хочу, чтобы надиктованный текст не пропадал, если я случайно закрыл окно.

Критерии приёмки:
- После закрытия и повторного открытия окна (в пределах активной сессии GNOME Shell) текст остаётся в поле ввода.

### US-6. Очистка поля

Как пользователь, я хочу быстро очистить поле для следующей диктовки.

Критерии приёмки:
- Кнопка «Очистить» стирает содержимое поля.
- Фокус остаётся в поле ввода после очистки (можно диктовать сразу).
